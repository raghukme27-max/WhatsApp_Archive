# Contributing to WhatsApp Archive

Thank you for considering a contribution to this project.

## How to contribute

### Reporting a bug
Open an issue on GitHub and include:
- What you expected to happen
- What actually happened
- Steps to reproduce
- Your operating system and Python version

### Suggesting a feature
Open an issue describing the feature and why it would be useful.

### Submitting code changes
1. Fork the repository.
2. Create a new branch from `main`: `git checkout -b my-change`
3. Make your changes.
4. Run the tests: `python -m unittest discover -s tests`
5. Commit your changes: `git commit -m "Description of your change"`
6. Push to your fork: `git push origin my-change`
7. Open a pull request against this repository.

## Code style
- Follow the existing formatting in the codebase.
- Keep changes small and focused on one issue.
- Do not commit secrets, tokens, or passwords.
